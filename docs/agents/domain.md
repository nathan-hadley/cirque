# Domain docs

Before exploring, read `CONTEXT.md` (the glossary) and any ADRs in `docs/adr/` that touch the area. If `CONTEXT.md` doesn't exist yet, carry on without it; `/domain-modeling` creates it when the first term is settled.

Use the glossary's terms in issue titles, names, and proposals. If your output contradicts an ADR, say so explicitly instead of quietly overriding it.
